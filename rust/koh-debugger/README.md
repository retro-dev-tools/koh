# Native debugger

`Debugger` operates on the caller's current `koh_emulator::machine::Machine`.
It never boots or replaces that machine. `handle` returns `Reply { response,
events, action }`; the host writes the response before events and applies the
action. `Action` is `None`, `Continue`, `Pause`, `StepIn`, `Next`, `StepOut` or
`Disconnect`. `handle_empty` serves configuration before a ROM is opened and
returns recoverable errors for inspection needing a machine.

`step(machine, action)` returns stopped events after one instruction. For CALL,
RST or step-out it installs a banked one-shot and returns an empty vector; the
host resumes and calls `run_frame` until it returns a stopped event. Persistent
breakpoints/watchpoints can stop that run earlier. `run_frame` checks after
instruction completion, preserving the reference's continue-at-current-PC
behavior. Existing memory hooks are composed and restored, including context
and HBlank callbacks. A real-machine regression compares every callback against
an undebugged frame. Instruction data
reads, including memory operands in breakpoint conditions, pass through the
actual machine bus; inspection uses debug reads.

`load_debug_info(path)` uses `koh_link::read_dwarf` and replaces metadata only
after successful validation. `clear_debug_info` clears metadata on host-owned
ROM replacement. The host must clear/reload metadata when it replaces the ROM;
queries always read registers/memory from the machine passed to the call.
`location_label(machine, pc)` supplies source labels for host diagnostics.

The port retains the managed flat execution-breakpoint set: setting source,
function or instruction breakpoints replaces that set. Only source breakpoints
have condition/hit-count fields in the reference request model. Watchpoint
conditions/hit counts are likewise ignored in the reference. Non-constant debug
banks above 255 are explicitly rejected. Native far-stack unwind markers are
validated; unknown/corrupt native recipes stop unwinding without guessing frames.
Register, hardware, symbol and source scopes preserve reference values and
ordering, including RamLabel names and hidden unwind markers.

## Independent oracle

`tests/oracle.cs` is a development-only capture program referencing unchanged
managed assemblies. Rust never loads it. `tests/disassemble.json` contains all
512 managed unprefixed/CB-prefixed decodes. `tests/responses.json` contains 28
managed DAP response objects. Tests compare full response objects, excluding
only outbound sequence numbers because the production host emits initialized
events and the managed unit dispatcher does not.
