# Rust LSP Implementation Plan

> Execute inline with superpowers:executing-plans and test-driven-development.

**Goal:** Replace managed koh-lsp with Rust, preserving the assembler worker.
**Architecture:** A synchronous stdio LSP server owns workspace state and editor
responses. A persistent child exchanges version-1 JSON lines with koh-asm.
**Tech stack:** Rust 2024, serde/serde_json, standard process and I/O APIs.
**Spec:** docs/rust-lsp/design.md (approved).

## Global constraints

Preserve all existing LSP methods, project isolation, overlays and UTF-16 spans.
Keep koh-asm --serve-json. No managed production fallback. Rust floor 1.88.
Preserve unrelated changes. Commit working increments; no push or merge.

## Review focus

Worker hangs must time out; stderr must not deadlock the protocol.
Malformed framing must not allocate unbounded memory or panic.
File URIs must survive spaces, Unicode and Windows drives.
Unsaved includes must stay isolated by project owner.
Configuration errors must not silently select heuristic mode.
